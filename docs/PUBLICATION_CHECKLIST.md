# ZFTI–2026 submission gate

The conference letter requires: full paper title, author name, affiliation, email, ORCID, abstract, keywords, main content, references. Deadline: 2026-10-30. Confirm page/font and accepted file type with the conference itself.

## Blockers before submission
- [ ] Official source clauses and their time intervals human verified
- [ ] Nontrivial independent, human-validated question sets
- [ ] Exact experiment scripts and split definitions preserved
- [ ] Tests run and results logged with uncertainty and error analysis
- [ ] Any AI assistance disclosed where required
- [ ] Bibliography checked against original paper or authoritative publisher
- [ ] Author personally approves results and interpretations
- [ ] Conference confirms review terms, acceptable preprint/public-repo status and payment sequence

**Current prototype does not meet these scientific submission conditions.**
